# Mimi RPG UI Asset Pack

Cropped from the supplied transparent UI sheet.

PNG = lossless master crops.
WEBP = optimized web copies for the website.

Included:
- Mimi portrait
- 8 stat icons
- 6 circular navigation buttons
- fantasy panels / HUD frames
- status buttons
- XP/HP/gold bar art
- decorative frame elements

The stat/navigation labels are mostly excluded so the app can render crisp live HTML text.
